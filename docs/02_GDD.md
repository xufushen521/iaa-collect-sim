# 七格收集三消 GDD

优先级：U1

## 产品定位

面向轻量休闲玩家的短局收集消除游戏。核心体验来自“可见选择、槽位压力、临门消除”，广告收入来自失败后对继续本局的真实需求。

## 核心循环

关卡选择 → 点击可访问牌 → 槽位归组 → 三消释放空间 → 七槽溢出 → 广告救援或重开 → 通关获取金币 → 使用金币购买洗牌/撤销。

## 玩家体验目标

- 前 2 关让玩家在低遮挡和少量符号下理解规则。
- 中段关卡通过层数和符号数增加选择成本，不只增加时长。
- 单次广告解决的是当前失败，而不是承诺必然通关。
- 金币提供可控的自我修正，不制造无法进入关卡的硬门槛。

## 难度杠杆

| 参数 | 增加后的主要影响 | 次要影响 | 建议 |
|---|---|---|---|
| 层数 | 可达牌减少、遮挡增加 | 平均操作数上升 | 每关逐级增加 |
| 符号数 | 槽内重复概率下降 | 溢出率上升 | 与牌数同步调整 |
| 牌数 | 单局变长 | 广告前沉没成本增加 | 避免只靠加牌拖时长 |
| 步数 | 只作为安全上限 | 低于牌数时直接不可通关 | 不得低于牌数 |
| 广告上限 | 增加继续机会 | 提高曝光但可能降低失败代价 | 首版每关 1 次 |

## 广告流程

1. 正常游戏，不显示 Banner 或插屏。
2. 槽满且仍有广告次数时，暂停并显示激励视频选择。
3. 玩家拒绝：关卡失败，进入重开或退出。
4. 玩家完成广告：移出槽内最多 3 张原牌，补 2 步，继续本局。
5. 广告完成只解决本次失败，不保证后续通关。

## 金币系统

### 来源

- 通关基础奖励 24。
- 每剩余 1 步奖励 1.5。
- 无道具通关奖励 8。

### 去向

- 洗牌 30。
- 撤销 18。

金币余额跨关携带。首版没有体力、入场费或金币购买 IAP，因此金币体系只验证“局内道具经济”而不与广告救援混账。

## 关卡状态

`playing` → `won`

`playing` → `failed` → `playing`（广告救援成功）

`playing` → `failed` → `failed`（拒绝广告或没有救援机会）

## 视觉与交互要求

- 当前可点击牌与已被遮挡牌必须有明显对比。
- 槽内同类牌需要连续排列，便于玩家看到“还差一张”。
- 槽位剩余 1 格时应出现压力反馈，而不是等失败后才提示。
- 广告入口只在失败状态出现，关闭广告后回到明确的重开/退出选择。

## 当前非目标

- 不复制任何具体产品的美术、角色、关卡棋阵或文案。
- 不把极低通关率作为成功的默认标准。
- 不用机器人通关率宣称真人留存。
