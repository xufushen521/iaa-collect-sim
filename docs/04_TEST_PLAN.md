# 七格收集三消验收与测试计划

优先级：U1

## 功能验收

| 编号 | 场景 | 通过标准 |
|---|---|---|
| F01 | 固定 seed 开局 | 两次生成相同的牌、层数和位置 |
| F02 | 点击被遮挡牌 | 操作被拒绝，状态不变 |
| F03 | 三张同类入槽 | 立即移除三张，槽位减少 3 |
| F04 | 七槽无三消 | 进入失败，失败原因为槽满 |
| F05 | 失败且广告可用 | 出现广告选择，不自动观看 |
| F06 | 广告救援 | 返回最多 3 张原牌、补 2 步、继续本局 |
| F07 | 撤销未消除操作 | 牌回到牌堆，步数恢复，扣除金币 |
| F08 | 撤销已消除操作 | 不允许 |
| F09 | 洗牌 | 牌数、层数和符号多重集不变，扣除金币 |
| F10 | 金币不足 | 道具不生效，记录买不起事件 |
| F11 | 清空牌堆与槽位 | 通关并写入金币奖励 |
| F12 | 导出日志 | CSV 字段与当前局事件一致 |

## 边界验收

- 牌数不能被消除数量整除时，配置校验失败。
- 步数小于牌数时，配置校验失败，因为每张牌至少需要点击一次。
- 广告上限为 0 时，不生成广告提供事件。
- 广告上限为 2 时，同一局最多完成 2 次救援。
- 返回槽内牌后仍有牌可访问时，状态必须回到 `playing`。
- 已通关或无撤销快照时，撤销按钮不可用。

## 回归验收

- 修改关卡参数后，同 seed 的结果仍可复现。
- 修改广告上限只影响广告机会，不改变初始牌面 seed。
- 修改金币价格不影响牌面生成和通关条件。
- 新增符号后，旧关卡只使用其声明的符号前 N 个。

## 自动测试

当前 `tests/` 覆盖层叠遮挡、三同消除、槽满、广告救援、撤销、洗牌、固定 seed、配置边界、广告上限和实验矩阵。

运行：

```powershell
python -m unittest discover -s tests -v
```
