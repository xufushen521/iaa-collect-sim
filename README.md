# IAA 七格收集三消

优先级：U1  
更新日期：2026-11-12

一个可玩的收集三消原型，用七格槽、三同消除、失败激励视频和金币道具验证 IAA 的核心闭环。参考通用机制，不复制任何游戏的 IP、素材、关卡或版式。

[配置工作簿](docs/iaa_collect_config.xlsx) · [美术需求](docs/iaa_collect_art_requirements.docx) · [实验报告](outputs/EXPERIMENT_REPORT.md) · [设计复盘](docs/05_ANALYSIS_REVIEW.md)

## 数据范围

- 当前版本不连接真实游戏、广告平台或线上分析系统，不能直接取得真实线上数据。
- 可以通过固定种子、机器人策略和事件日志模拟“线上行为数据”。
- 合成结果只能用于模型内参数比较，不能推断真实 DAU、留存、eCPM、广告收入或市场基准。
- 事件结构与指标口径可直接替换为后续真实埋点导出。

## 当前模拟结果

固定种子 `20261110`，混合操作策略：

| 广告救援上限 | 通关率 | 人均广告观看 |
|---|---:|---:|
| 0 次 | 35.5% | 0.00 |
| 1 次 | 51.3% | 0.47 |
| 2 次 | 61.1% | 0.67 |

第一次救援提升约 15.8 个百分点，第二次只再提升约 9.8 个百分点。首版因此保留每关 1 次广告。

完整结果见 [实验报告](outputs/EXPERIMENT_REPORT.md)，设计与口径见 [复盘](docs/05_ANALYSIS_REVIEW.md)。配置工作簿随仓库提供。

## 启动

双击 `启动试玩.bat`，或在当前目录运行：

```powershell
python -m streamlit run app.py
```

## 重新生成数据

```powershell
python scripts/run_simulation.py --players 300 --campaign-players 500
python -m unittest discover -s tests -v
```

## 数据链路

`参数配置 → 层叠牌堆 → 七格槽 → 三消/溢出 → 广告救援 → 金币收支 → 事件日志 → 策略/广告档对比`

批量结果来自机器人策略和假设参数，不是线上经营数据。
